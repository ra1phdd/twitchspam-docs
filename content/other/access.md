Роли и доверенные пользователи позволяют выдавать отдельные права без выдачи полного доступа модератора.

### Доступные скоупы
| Скоуп | Право |
|-------|-------|
| `noas` | Игнорировать антиспам |
| `nomw` | Игнорировать запрещённые слова |
| `nobw` | Игнорировать банворды |
| `noad` | Игнорировать фильтр рекламы |
| `mod` | Использовать модераторские действия |
| `nuke` | Использовать массбан |
| `poll` | Управлять опросами |
| `pred` | Управлять ставками |

### `!trust`
Выдаёт пользователям отдельный скоуп.

**Формат:**
`!trust <скоуп> <пользователи>`

Пример:
```text
!trust nuke user1 user2
```

---

### `!trust del`
Удаляет у пользователей отдельный скоуп.

**Формат:**
`!trust del <скоуп> <пользователи>`

---

### `!trust list`
Показывает доверенных пользователей. Если указан пользователь, список фильтруется по нему.

**Формат:**
`!trust list <*пользователь>`

---

### `!role add`
Создаёт или дополняет роль набором скоупов.

**Формат:**
`!role add <роль> <скоупы>`

Пример:
```text
!role add nuker nuke,mod
```

---

### `!role del`
Удаляет роль целиком или удаляет из неё указанные скоупы.

**Формат:**
`!role del <роль> <*скоупы>`

---

### `!role trust`
Выдаёт роль пользователям.

**Формат:**
`!role trust <роль> <пользователи>`

---

### `!role untrust`
Удаляет роль у пользователей.

**Формат:**
`!role untrust <роль> <пользователи>`

---

### `!role list`
Показывает роли, их скоупы и пользователей с этими ролями. Если указана роль, список фильтруется по ней.

**Формат:**
`!role list <*роль>`
