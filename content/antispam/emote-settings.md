Эти настройки контролируют спам с использованием эмоутов в сообщениях.  
**Подробное описание команд см. в разделе [Настройки для обычных пользователей](#настройки-для-обычных-пользователей).**

### Список команд эмоутов
- `!emote on` — включить антиспам для эмоутов.
- `!emote off` — отключить антиспам для эмоутов.
- `!emote msg <значение>` — количество похожих сообщений, состоящих только из эмоутов (2–15).
- `!emote p <наказания>` — последовательность наказаний за спам эмоутами.
    - **Наказания:**
        - `*` — скопировать наказания из команды `!p`
        - `n`, `none` — не выдавать наказание
        - `d` — удалить сообщение
        - `w`, `warn` — предупредить пользователя и удалить сообщение
        - `1-1209600` — таймаут в секундах
        - `b`, `ban`, `0` — бан
- `!emote rp <значение>` — время сброса счётчика наказаний для эмоутов (1–86400).
- `!emote mlen <значение>` — ограничение количества эмоутов в сообщении (0–30).
- `!emote mp <наказание>` — наказание за превышение количества эмоутов.
    - **Наказания:**
        - `*` — скопировать **первое** наказание из команды `!emote p`
        - `n`, `none` — не выдавать наказание
        - `d` — удалить сообщение
        - `w`, `warn` — предупредить пользователя и удалить сообщение
        - `1-1209600` — таймаут в секундах
        - `b`, `ban`, `0` — бан

Пример:
```text
!emote msg 3
!emote mlen 10
!emote p d
```
