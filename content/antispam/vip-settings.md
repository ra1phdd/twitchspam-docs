Для VIP-пользователей действуют свои настройки, которые могут отличаться от обычных пользователей.  
**Подробное описание команд см. в разделе [Настройки для обычных пользователей](#настройки-для-обычных-пользователей).**

### Список команд
- `!vip on` — включить антиспам для випов.
- `!vip off` — отключить антиспам для випов.
- `!vip sim <значение>` — порог схожести сообщений для випов (0.1–1.0).
- `!vip msg <значение>` — количество похожих сообщений для випов (2–15).
- `!vip p <наказания>` — последовательность наказаний для випов.
  - **Наказания:**
    - `*` — скопировать наказания из команды `!p`
    - `n`, `none` — не выдавать наказание
    - `d` — удалить сообщение
    - `w`, `warn` — предупредить пользователя и удалить сообщение
    - `1-1209600` — таймаут в секундах
    - `b`, `ban`, `0` — бан
- `!vip rp <значение>` — время сброса счётчика наказаний для випов (1–86400).
- `!vip mlen <значение>` — максимальная длина слова для випов (0–500).
- `!vip mp <наказание>` — наказание за превышение длины слова для випов.
  - **Наказания:**
    - `*` — скопировать **первое** наказание из команды `!vip p`
    - `n`, `none` — не выдавать наказание
    - `d` — удалить сообщение
    - `w`, `warn` — предупредить пользователя и удалить сообщение
    - `1-1209600` — таймаут в секундах
    - `b`, `ban`, `0` — бан
- `!vip mg <значение>` — минимальное количество разных сообщений между спамом для випов (0–15).

Пример:
```text
!vip sim 0.8
!vip msg 4
!vip p *
```
