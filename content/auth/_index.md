Twitch требует, чтобы создатели ботов запрашивали у пользователей прохождение авторизации для получения доступа к определённым функциям. Для ее прохождения перейдите по **[ссылке](https://api.r1ph.com/afsyggabot/auth)**.

### `!auth`
Проверяет, пройдена ли авторизация канала. Если сохранённый токен устарел, бот попытается обновить его автоматически.

### Отмена авторизации
Для отмены авторизации отключите приложение в настройках Twitch:

`Настройки → Подключения → aFsYGGABot → Отключить`
